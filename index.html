Independent write-up by one Modrinth creator. Not affiliated with or endorsed by Modrinth.

Modrinth’s AI policy is not applied evenly.

My submission disclosed its AI use in detail and was refused on both grounds: content (§6.2b) and icon (§6.2a). Projects disclosing the same, or more, were approved after the grace period ended on 27 September 2026.

refused 2026-11-09 after 38.4 h §6.2b: no evidence cited §6.2a: icon 17 comparable projects approved after the deadline

1. The refusal

My disclosure:

“[This project] was made together with Claude (Anthropic). Most of the code, the documentation and this page’s text were written by Claude under my direction, and I tested everything in game. The pixel-art icon was drawn by a small script Claude wrote, not by an image generator.”

Submitted 2026-11-08 06:01 UTC, rejected 2026-11-09 20:25 UTC with two issues:

§6.2b “…this project is not suitable to be published publicly on Modrinth. If you believe this is incorrect, please provide significant evidence that your project consists of primarily non-AI-generated content. Otherwise, we ask that you do not resubmit.”

§6.2a “…images created or significantly altered with AI are not permitted… Please remove the following AI images: Project icon.”

The §6.2a message names and links the image it objects to. The §6.2b message cites no evidence: no file, passage or excerpt (both issues carry an empty locations field). Because §6.2b also asks me not to resubmit, replacing the icon cannot bring the project back. The project page’s own banner says the opposite: Please address all moderation concerns, including any issues listed in messages below, before resubmitting this project.

Issue text quoted from the moderation record as captured 2026-11-10 03:47 UTC; banner text as shown on the project page on 2026-11-14. “§6.2a” and “§6.2b” are the labels used in the moderation messages; the rules page itself has one §6.2. Note that §6.1 requires disclosure when “a substantial portion of the project's code is a product of AI output”, so substantial AI code is allowed; only content “primarily or entirely” from AI is not. Rule text: Content Rules §6, archived 2 Nov 2026 (unchanged since added; absent on 2 Aug). Grace period: policy announcement.

5. What I ask

Not that any project above is removed. I would not report them.

  1. State the §6.2b threshold. If “most of the code by AI” fails it, Backrooms, PVP Tiers, Fluidic and others fail too. If human direction, review and testing pass it, my disclosure described exactly that.
  2. State the §6.2a threshold for images drawn by AI-written scripts.
  3. Cite evidence in §6.2b findings, as §6.2a findings already do.
  4. Apply the same reading to everyone. I will rebuild to whatever the standard is.
